# Video Tutorials

Short, silent screen recordings with captions, one topic each. They were recorded on macOS, and the dashboard works the same on Windows and Linux. Each installer has its own video.

**Follow along:** download the [demo MIDI files](https://github.com/Metacreation-Lab/midigpt-REAPER/tree/main/docs/tutorials/demo) (free to use, CC0) and drag one into an empty REAPER project.

Videos marked *coming soon* are still being recorded.
