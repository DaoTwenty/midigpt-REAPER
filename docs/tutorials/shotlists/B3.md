# B3 · Your first generation (infill)

**Target length:** about 2 min · **Captions:** [`captions/B3.srt`](../captions/B3.srt) (draft timing ≈ 45 s; retime to the recording)

## Starting state

`pop_groove.mid` imported and set up, server running (Yellow), all settings at defaults, Variations 1.

## Steps

1. Drag a time selection over bars 1–8.
2. Split the bass item at bars 5 and 7, select only the bars 5–6 piece.
3. Click **Generate**. Show the Information tab's progress ("Waiting for the server...", and "Streaming -- N note(s) received so far..." if the server streams), then the token bar.
4. Play bars 1–8.
5. Undo (Cmd+Z), play again (the original is back). Redo (Cmd+Shift+Z).

## Must be visible

- Time selection and the selected item at the same time
- Progress text while generating
- The written-back notes
