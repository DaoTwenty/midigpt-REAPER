3. Case 3: "Can't add instruments: the Arachno SoundFont isn't downloaded (re-run the installer)." Re-run the installer, answer y to Arachno.
4. Mention the AU/CLAP-only message and the macOS-only manual import fallback (VST.md).
5. Check the track's FX: a Sforzando instance with an Arachno preset loaded.
