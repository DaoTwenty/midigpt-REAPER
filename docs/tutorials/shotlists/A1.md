# A1 · What MIDI-GPT for REAPER does

**Target length:** about 60 s · **Captions:** [`captions/A1.srt`](../captions/A1.srt) (draft timing ≈ 49 s; retime to the recording)

## Starting state

`pop_groove.mid` imported, Setup Tracks already run, server running (Yellow), dashboard open next to the arrange view. Variations set to 3.

## Steps

1. Play bars 1–8 briefly so the viewer hears the song.
2. Drag a time selection over bars 1–8.
3. Select the lead item, split it so bars 5–8 are their own item, and select that item only.
4. Click **Generate**. Let the progress bar run.
5. Click candidates 1, 2, 3, playing bars 5–8 after each.
6. Settle on one and play bars 1–8.

## Must be visible

- The 3 candidate buttons after generation
- The new notes in the lead track
