# B5 · Variations and the candidate picker

**Target length:** about 90 s · **Captions:** [`captions/B5.srt`](../captions/B5.srt) (draft timing ≈ 39 s; retime to the recording)

## Starting state

`pop_groove.mid` set up, server running, the lead in bars 5–8 selected, time selection bars 1–8.

## Steps

1. Set **Variations to generate** to 4. Show the placeholder candidate row.
2. **Generate**. Note the Information tab says the token bar isn't available for batches.
3. Hover a candidate to show its seed; click 1–4, playing after each.
4. If a candidate fails (greyed), hover it to show why.
5. Pick one. Undo (Cmd+Z) removes the batch result.

## Must be visible

- Candidate buttons
- Seed tooltip
