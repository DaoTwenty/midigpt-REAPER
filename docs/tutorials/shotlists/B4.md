# B4 · Generate a brand-new part

**Target length:** about 2–3 min · **Captions:** [`captions/B4.srt`](../captions/B4.srt) (draft timing ≈ 54 s; retime to the recording)

## Starting state

`pop_groove.mid` set up, server running. Delete nothing.

## Steps

1. Insert a new track, name it `cello` (show INSTRUMENTS.md briefly for the name list).
2. Create an empty MIDI item over bars 1–8 on it (Insert > New MIDI item with the time selection over bars 1–8), and select it.
3. In the dashboard, expand the `cello` track: tick **A**. In Core: tick **Limit voices** (Minimum 1, Maximum 2).
4. Optional: Setup Selected Tracks on it so it plays with a cello sound.
5. Time selection bars 1–8. **Generate**. Play.

## Must be visible

- Naming the track
- The empty item selected
- A ticked
