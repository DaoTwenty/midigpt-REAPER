# A2 · Install on macOS

**Target length:** 3–4 min (speed up the long steps) · **Captions:** [`captions/A2.srt`](../captions/A2.srt) (draft timing ≈ 91 s; retime to the recording)

## Starting state

A Mac with REAPER installed and opened once, Python 3.10–3.12 and git. No previous MIDI-GPT install (`./dev/dev_reset.sh` if needed). REAPER open, to show the "close REAPER" prompt.

## Steps

1. Open the GitHub **Releases** page, download `MIDI-GPT-for-REAPER-v0.1.0.zip`, unzip it.
2. Double-click `Install - Mac.command`. If macOS won't open it, allow it under System Settings > Privacy & Security (Open Anyway) and double-click again.
3. Answer **y** to "Close REAPER now and continue?"
4. Let steps 1–6 run (speed up 4–8× in the edit; keep the step headings readable).
5. Pause on the expected `[WARN] No published checksum for ReaImGui` line.
6. At "Open the Sforzando download page", answer **y**. In the browser, download and run Sforzando's installer, keeping **VST** and/or **VST3** ticked.
7. Answer **y** to "Download the Arachno GM SoundFont (~140MB) now?"
8. Answer **n** to "Launch server?" (covered in A6). Close the window.
9. Show the **Start MIDI-GPT Server** shortcut on the Desktop.

## Must be visible

- Each `Step N/6` heading
- The ReaImGui warning, called out as expected
- Sforzando installer's plug-in format page with VST/VST3 ticked
- "Installation Complete!"
