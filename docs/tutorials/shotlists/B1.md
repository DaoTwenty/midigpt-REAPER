# B1 · Dashboard tour

**Target length:** about 2 min · **Captions:** [`captions/B1.srt`](../captions/B1.srt) (draft timing ≈ 46 s; retime to the recording)

## Starting state

`pop_groove.mid` imported, Setup Tracks run, server running, dashboard open.

## Steps

1. Hover over each of the 6 areas in order: banner, Setup (top right), Global Settings (middle left), Tracks (middle right), Information/Console (bottom left), Generation (bottom right).
2. Click through the 4 Global Settings tabs without changing anything.
3. Expand one track header; show the I and A boxes and the Core/Pitch/Remix tabs.
4. Switch Information ↔ Console.
5. Save the project, close and reopen it, reopen the dashboard: settings are still there.

## Must be visible

- All 6 areas
- Settings surviving a project reopen
