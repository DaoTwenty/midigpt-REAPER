# D5 · Can't reach the server

**Target length:** about 90 s · **Captions:** [`captions/D5.srt`](../captions/D5.srt) (draft timing ≈ 35 s; retime to the recording)

## Starting state

Server stopped. `pop_groove.mid` set up with a selection ready.

## Steps

1. Open the dashboard: "Model: server not reachable" with **Retry**.
2. Click **Generate**: the Error popup "Cannot reach server at http://127.0.0.1:3456: ...". OK.
3. Start the server from the Desktop shortcut; wait until ready.
4. Click **Retry**. Model appears. **Generate** works.
5. Remote server: check the address with **Change...** and the firewall on the server machine (C6).

## Must be visible

- The error popup
- Retry bringing the model back
