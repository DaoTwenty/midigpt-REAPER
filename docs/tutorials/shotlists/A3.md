# A3 · Install on Windows

**Target length:** 3–4 min · **Captions:** [`captions/A3.srt`](../captions/A3.srt) (draft timing ≈ 62 s; retime to the recording)

## Starting state

Windows 10/11 64-bit with REAPER 64-bit installed and opened once, Python 3.10–3.12 and git. Ideally without the Microsoft Visual C++ Runtime, to show that prompt. No previous install (`.\dev\dev_reset.ps1`).

## Steps

1. Download and extract the release zip (right-click > Extract All).
2. Double-click `Install - Windows.bat`.
3. At "Download and install it from Microsoft now? [Y/n]" press Enter, accept the UAC prompt.
4. Same prompts as A2: close REAPER (y), Sforzando page (y, keep VST3 ticked), Arachno (y), Launch server (n).
5. Show `Start MIDI-GPT Server` on the Desktop.

## Must be visible

- The Visual C++ Runtime prompt and UAC
- Each `Step N/6` heading
- "Installation Complete!"
