# A5 · Load the dashboard and pin it

**Target length:** about 90 s · **Captions:** [`captions/A5.srt`](../captions/A5.srt) (draft timing ≈ 50 s; retime to the recording)

## Starting state

REAPER open with an empty project, after a successful install.

## Steps

1. Actions > Show Action List > **Load ReaScript...**
2. Navigate to `Scripts/MIDI-GPT/` in the REAPER resource folder, select `MIDI-GPT.py`, Open.
3. With the action selected, click **Run** — the dashboard opens.
4. Back in the Action List, with MIDI-GPT.py selected: Shortcuts **Add...**, press a key (e.g. Shift+M), OK.
5. Right-click the main toolbar > Customize toolbar... > Add... > search `MIDI-GPT.py` > Select/close. Save.
6. Close the dashboard, reopen it from the toolbar button.

## Must be visible

- The file list showing the 5 .py files
- The new toolbar button

## Notes

- Menu names are REAPER's; check them against the REAPER version you record with.
