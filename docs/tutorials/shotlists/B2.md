# B2 · Setup Tracks

**Target length:** about 3 min · **Captions:** [`captions/B2.srt`](../captions/B2.srt) (draft timing ≈ 74 s; retime to the recording)

## Starting state

Fresh project with `pop_groove.mid` imported (tracks named drums, bass, keys, lead, no instruments). First Setup Tracks on this machine, so the conversion message shows.

## Steps

1. Click **Setup Tracks**. Show the "Set Up Tracks" popup: keep "Track names + instruments" and "Auto-detect". **Run**.
2. Switch to Console: "Converting the Arachno SoundFont…" then one line per track.
3. Show the track names changed (e.g. bass → electric_bass_finger, keys → electric_piano_1, lead → flute). Play.
4. Undo (Cmd+Z), then **Setup Tracks** again with "Auto-detect, but let me confirm/override each one": show the "Confirm Track Instruments" list, change keys to another instrument, **Apply**.
5. Select one track, click **Setup Selected Tracks**: show "If a track already has an instrument" > **Replace it**.
6. Mention "Track names only" for people with their own synths.
