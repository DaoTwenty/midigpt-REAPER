# A4 · Install on Linux

**Target length:** 3–4 min · **Captions:** [`captions/A4.srt`](../captions/A4.srt) (draft timing ≈ 60 s; retime to the recording)

## Starting state

A Linux desktop (e.g. Ubuntu 24.04) with REAPER installed from its tarball and opened once, Python 3.10–3.12 and git. No previous install (`./dev/dev_reset.sh`).

## Steps

1. Download "sforzando for Linux (beta)" from plogue.com/downloads.html, unzip, run `./install_sforzando.sh` in a terminal (no sudo; it asks for the password).
2. Download and unzip the release, run `./Install\ -\ Linux.sh` (or double-click if the file manager runs scripts).
3. Answer y to close REAPER, then let steps 1–6 run.
4. Pause on `[OK] VST plug-in paths: ...;/usr/lib/vst3`.
5. Answer y to Arachno, n to Launch server.
6. Open REAPER: Options > Preferences > Plug-ins > VST, show `/usr/lib/vst3` in the path list and **sforzando (VST3)** in the FX browser.

## Must be visible

- The beta note
- The vstpath line
- sforzando (VST3) in REAPER's FX browser
