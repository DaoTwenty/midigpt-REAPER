# A6 · Start the server and connect

**Target length:** about 2 min · **Captions:** [`captions/A6.srt`](../captions/A6.srt) (draft timing ≈ 46 s; retime to the recording)

## Starting state

Installed, dashboard pinned, server NOT running. REAPER open with the dashboard showing "Model: server not reachable".

## Steps

1. Point at "Model: server not reachable" and the **Retry** button in the dashboard.
2. Double-click **Start MIDI-GPT Server** on the Desktop. Terminal opens with "MIDI-GPT Server Starting...".
3. First launch downloads the model (speed up). Wait until it's ready.
4. In the dashboard click **Retry**: the model picker and the architecture label (`yellow`) appear.
5. Show the `Server:` line and **Change...** (details in C6).
6. Show stopping: Ctrl+C in the terminal.
7. Optional: run `./start_midigpt_server.sh --pretrained prism_medium` to show another model (details in C7).

## Must be visible

- The terminal window
- Model picker + architecture label after Retry
