# Tutorial demo files

Short MIDI files used in the MIDI-GPT for REAPER video tutorials, so you can follow along. Drag one into an empty REAPER project. In REAPER's import dialog, import the file's tempo map and put each MIDI track on its own REAPER track.

| File | What's in it | Used in |
|---|---|---|
| `pop_groove.mid` | 8 bars at 120 bpm, C–Am–F–G. Four tracks: `drums` (channel 10), `bass` (electric bass), `keys` (electric piano), `lead` (flute). | Most usage videos and scenarios |
| `piano_sketch.mid` | 8 bars at 96 bpm, one `piano` track (broken chords and a melody). | Infill, Remix and pitch-mask examples |
| `pickup_song.mid` | The pop groove with a one-beat pickup, so the song's downbeats fall on beat 2 of REAPER's bars. | The off-grid selection warning |

The track names are deliberately informal (`bass`, `keys`, `lead`), as they'd be in a real session. **Setup Tracks** detects the instruments from the MIDI content and renames the tracks to their General MIDI names.
