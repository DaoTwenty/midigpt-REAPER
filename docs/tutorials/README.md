# Recording the tutorial videos (maintainers)

The published list of videos is [TUTORIALS.md](../../TUTORIALS.md). This folder holds what's needed to make them:

- `shotlists/<ID>.md`: starting state, steps, and what must be on screen.
- `captions/<ID>.srt`: the captions. They double as the script, so read them before recording.
- `demo/`: the demo MIDI files viewers can download (generated by `dev/make_demo_midi.py`).

Raw recordings go in `tutorials-raw/` and rendered videos come out in `tutorials-out/`. Both are at the repo root and gitignored.

## Setup (once)

- **Recorder:** [OBS Studio](https://obsproject.com/), canvas and output at 1920×1080, 30 fps, format `.mov` or `.mp4`.
- **ffmpeg with libass and freetype**, used to burn in captions. Homebrew's default `ffmpeg` has neither. Either install `brew tap homebrew-ffmpeg/ffmpeg && brew install homebrew-ffmpeg/ffmpeg/ffmpeg`, or download the static `ffmpeg` and `ffprobe` from [evermeet.cx](https://evermeet.cx/ffmpeg/) and point the script at them with `FFMPEG=… FFPROBE=…`.
- **A caption timing editor** (optional): [Subtitle Edit](https://www.nikse.dk/subtitleedit) or [Aegisub](https://aegisub.org/). Any text editor works too.

## Recording standard

- **Clean REAPER:** a separate portable REAPER install for recording, with the default theme and the window at 1920×1080. Use the dashboard's **Dark** theme.
- **Clean desktop:** Do Not Disturb on, Dock hidden, no other windows. Turn on macOS *Accessibility › Display › Pointer size* (one step up) so the cursor is easy to follow.
- **Layout:** place the dashboard (fixed at 800×600) so the bottom ~120 px of the frame stay clear. That's where the captions go.
- **Pace:** move slowly, and pause for about a second after each click so the result is visible. Don't rush waits; long ones (installs, first model download) are sped up in editing.
- **No audio needed.** The render script adds a silent track.
- **Starting state:** every shot list begins with one. Set it up exactly, so the videos match each other.

## Workflow per video

1. Read `shotlists/<ID>.md` and `captions/<ID>.srt`, and set up the starting state.
2. Record, following the steps. Save the file as `tutorials-raw/<ID>.mov`.
3. Retime `captions/<ID>.srt` to the recording. The draft timings are only estimates based on reading speed. Keep the text; if something on screen differs from a caption, fix the caption and check the wording against the app.
4. Render: `./dev/render_tutorials.sh <ID>`. This adds a 2-second title card taken from the shot list's first line and burns in the captions (shifted by the card's length automatically).
5. Watch `tutorials-out/<ID>.mp4` once on a laptop and once on a phone: can every caption be read, and does none cover what's being clicked?
6. Upload it to YouTube (see below), then replace *coming soon* in [TUTORIALS.md](../../TUTORIALS.md) with a link, and run `python3 build_docs.py`.

## Caption rules

- At most 2 lines of about 42 characters, one idea per caption, and at least 1.8 s on screen.
- Quote UI labels exactly as they appear, e.g. "Setup Selected Tracks" and "Replace it".
- On macOS, write shortcuts as Cmd (Cmd+Z). If Windows/Linux differ in a way that matters, mention both.
- Describe what the viewer should notice, not every click.

## YouTube

- One playlist per series: Getting Started (A), Using the Dashboard (B), Scenarios (C), Gotchas and Troubleshooting (D).
- Title: `MIDI-GPT for REAPER · B3 · Your first generation`.
- Description: one line on what the video shows, a link to the matching docs section and to the demo files, and "Recorded with MIDI-GPT for REAPER v0.1.0".
- Optionally, also upload the `.srt` as closed captions (Subtitles › Upload file › With timing), which lets YouTube auto-translate them. Viewers who turn CC on see the text twice, so leave CC off by default. Use the *rendered* timing, i.e. add 2 s for the title card: `ffmpeg -itsoffset 2 -i captions/B3.srt B3-youtube.srt`.
- In [TUTORIALS.md](../../TUTORIALS.md), link each title as `[Title](https://youtu.be/<id>)`. Add a thumbnail with `[![Title](https://img.youtube.com/vi/<id>/mqdefault.jpg)](https://youtu.be/<id>)` if you want one.

## When the app changes

Re-record only the videos whose shot lists mention the part of the UI that changed, and update the version in their YouTube descriptions. Caption-only fixes just need step 4 again.
